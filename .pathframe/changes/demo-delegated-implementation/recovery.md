## Failures

- Verification failure, changed-file scope violation, malformed Pinky result, lost lease, or implementation that does not meet the approved objective.

## Recovery

- Inspect the diff and Pathframe diagnostics; request changes for a recoverable task, release a lost lease only by exact lease id, or replan when the approved scope/dependencies are insufficient. Brain remains prohibited from implementing a leased task as fallback.
