## Objective

Add the minimum login/logout boundary using Laravel's existing session guard and User model so audit writes and reads have a trustworthy authenticated actor.

## Required Reads

- context/inspection.md
- intent.md
- requirements.md
- design.md

## Write Scope

- The minimal existing route/controller path for session login/logout.
- Focused authentication feature test(s).

## Constraints

- No package, token authentication, registration, password reset, or admin UI.
- Use Laravel password hashing and session guard; never write credentials to audit events.
- Preserve existing public user-list behavior.

## Verification

- ["php", "artisan", "test", "--filter", "Auth"]

## Acceptance

- Valid credentials establish a session actor, logout removes it, invalid/unauthenticated requests are denied, and focused tests pass.

## Questions

- none

## Assumptions

- The existing session guard is sufficient for this disposable demo when routes use the web middleware.
